## HTTP Status Codes

```
GET /odata/customers
    ? 200 OK with list of customers

GET /odata/customers('ALFKI')
    ? 200 OK with customer data
    ? 404 Not Found if customer doesn't exist

POST /odata/customers
    ? 201 Created with Location header
    ? 400 Bad Request if validation fails

PATCH /odata/customers('ALFKI')
    ? 204 No Content (updated)
    ? 404 Not Found if customer doesn't exist

DELETE /odata/customers('ALFKI')
    ? 204 No Content (deleted)
    ? 404 Not Found if customer doesn't exist
```

## OData Query Examples

```
List all with paging:
  GET /odata/customers?$top=20&$skip=0

Filter:
  GET /odata/customers?$filter=country eq 'USA'

Search:
  GET /odata/customers?$filter=contains(companyName,'Ltd')

Sort:
  GET /odata/customers?$orderby=companyName asc

Select specific columns:
  GET /odata/customers?$select=customerId,companyName

Expand relationships:
  GET /odata/customers?$expand=orders

Combine:
  GET /odata/customers?$filter=country eq 'USA'&$select=customerId,companyName&$orderby=companyName&$top=10
```

## Generic Repository Implementation Flow

```
GenericRepository<T>
    ?
Constructor: Store NorthwindContext and DbSet<T>
    ?
GetQueryable()
    ?? return _dbSet.AsQueryable()
       ?? Returns queryable for LINQ/OData filtering
    ?
GetByIdAsync(id)
    ?? return await _dbSet.FindAsync(id)
       ?? Retrieves single entity by primary key
    ?
GetAllAsync()
    ?? return await _dbSet.ToListAsync()
       ?? Retrieves all entities (be careful with large sets!)
    ?
AddAsync(entity)
    ?? await _dbSet.AddAsync(entity)
       ?? Marks entity for insertion
    ?
UpdateAsync(entity)
    ?? _dbSet.Update(entity)
       ?? Marks entity for update
    ?
DeleteAsync(id)
    ?? entity = await GetByIdAsync(id)
    ?? _dbSet.Remove(entity)
       ?? Marks entity for deletion
    ?
SaveChangesAsync()
    ?? await _context.SaveChangesAsync()
       ?? Persists all changes to database
```


## Async/Await Pattern

```
Non-Async (DON'T USE):
    var customer = _context.Customers.Find(id);    ?

Async (CORRECT):
    var customer = await _repository.GetByIdAsync(id);    ?
    
Why?
    • Doesn't block thread pool
    • Better scalability
    • Better for I/O operations
    • Required for async OData queries
```

## Error Handling Pattern

```
Try/Catch with Logging:
    try
    {
        await _repository.AddAsync(entity);
        await _repository.SaveChangesAsync();
        return Created(location, entity);
    }
    catch (DbUpdateException ex)
    {
        _logger.LogError(ex, "Error adding entity");
        return StatusCode(500, "Error creating resource");
    }
```
